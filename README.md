# Church Slavonic Bible UTF-8

A collection of Church Slavonic Bible and related text files encoded in UTF-8.

This repository exists to make finding and working with Church Slavonic texts easier.  
I gathered UTF-8 Church Slavonic files from various sources and placed them into a single repository so others do not have to spend time searching for them individually.

## Contents

- Church Slavonic UTF-8 text files
- Bible books and related texts
- Plain text files suitable for programming, NLP, search, OCR, and research
